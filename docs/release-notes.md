# GPT 娘 · Windows 1.0.1

Windows 10/11 x64。提供每用户安装程序、单文件便携程序和完整便携 ZIP。

- 三行 Codex 额度气泡：剩余百分比、重置时间、可用重置次数。
- 按压位置决定人物局部形变，按住时长决定发射速度与仰角。
- 抛物线发射、随机五次反弹后淡出、持续十秒的 GPT 雨。
- 恰好双击展开十项轮盘；三次及以上连点按普通发射处理。
- Minecraft 受击与经验音效由官方资源服务器按需下载并校验，提供两个试听按钮。
- 用户级自启动监视器，遵守持久保存的显示、隐藏与退出选择。
- 修正小角色抠图后的白色背景残留与网格边缘碎片，保留封闭轮廓内的白发及独立装饰。

第一次启动后，从系统托盘可选择显示、刷新额度、模式、音效测试和自动打开。
额度来自本机 Codex CLI 的已登录账号；未找到 CLI 时，请按 README 安装官方 CLI 并登录。

安装程序文件名含 `setup`；直接运行版含 `portable`；ZIP 解压后运行 `Codex Quota Pet.exe`。
便携版启用自动打开后，请将程序保留在固定位置。

源码采用 MIT 许可证；角色图授权范围见 ASSETS.md。
本发布未购买 Windows 代码签名证书，因此可执行文件没有发布者签名。
自动测试与界面截图由 GitHub 的 Windows runner 生成；用户账号额度、实际机器的缩放和虚拟桌面行为需要在使用机器上验证。
