# Asset provenance

The project includes two image files: `assets/gpt_quota_pet.png` and `assets/mini_gpt_sheet_original.png`. The user who supplied these images explicitly authorized their inclusion in this public repository. The large image was edited/generated from a user-supplied reference image; the sprite sheet image was supplied by the user.

The project was inspired by the user-provided reference repository [Sutera-Diffusus/dsh-whale-musume](https://github.com/Sutera-Diffusus/dsh-whale-musume). No code or images were copied from that repository. This acknowledgment does not claim authorship of the inspiration project.

The image authorization is limited to including these supplied images with this repository. It does not make the images part of the MIT-licensed code grant or grant a blanket license to third-party artwork. Do not infer additional reuse rights beyond the user's stated authorization.

Minecraft sound files are not included in this repository or packaged app. The app fetches the relevant objects at runtime from the Minecraft resource server and verifies SHA-1 hashes from Mojang's [asset index](https://piston-meta.mojang.com/v1/packages/32a06dd28a0a8a981f4a1dffbdb3931f3075ca6c/34.json).
